# Retrospective 20250522

我一直以为我很熟悉 Git 的 workflow，直到我自己使用 Git 管理我自己的软件的时候。我才发现是我太天真了。此话怎讲？在编写我自己的软件时，我时常有了新的 idea 的时候重构了旧的代码。重构着，重构着。就把旧代码给弄丢了。当我再想使用它的时候，它早已经淹没再茫茫的 commites 之海当中。后来回想到 Git 还有 branch 的功能。于是我豁然开朗，我想我以后再有新的 idea 就切换到新的 branch 继续开发。在开发完成后再合并到主线中。

另一个是在互联网上冲浪时，发现了一个新的现代的版本控制软件。名字是 jujutsu。有一名 Google 的工程师开发。完全兼容 Git。看过一个博主的介绍视频，感觉十分新颖和强大。后面也可在一些项目中尝试。

最后，我现在还在犹豫中。我想购买一套电脑零件，自己 DIY 一个整机。但是需要 6400。我有些不舍得。我想尝试向我自己贷款（果然，我狠起来连自己都会剥削），来支付这笔费用。我想设定的利息为年化百分之 6。然后每个月都有 1500 的零花钱入账。每周六也可尝试一下滴滴的兼职司机。
